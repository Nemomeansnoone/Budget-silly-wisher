silly wisher if it ran out of budget and was a command line tool

a unix executable is provided (compiled for macos, im not sure if it works on linux), or you can choose to run the python file yourself

windows:
install python, then cd to the directory where budget silly wisher is and run
python budget-silly-wisher.py

macos:
cd to the directory where budget silly wisher is and run
python3 budget-silly-wisher.py

linux:
cd to the directory where budget silly wisher is and run
python3 budget-silly-wisher.py
